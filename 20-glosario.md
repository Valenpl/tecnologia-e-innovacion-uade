# 20 · Glosario

> Definiciones breves de todos los términos de la materia, en orden alfabético, con el módulo donde se desarrollan. Usalo para consultar, no para estudiar: el desarrollo completo está en cada módulo.

| Término | Definición breve | Módulo |
|---|---|---|
| **5 V de Big Data** | Volumen, Velocidad, Variedad, Veracidad y Valor (la más importante). | [06](06-big-data.md) |
| **Abismo de desilusión** | Fase del Hype Cycle de Gartner donde caen las expectativas tras el pico. | [08](08-curvas-de-la-tecnologia.md) |
| **Aceleradora corporativa** | Estructura interna que da mentoría, recursos e infraestructura a emprendedores a cambio de pilotar soluciones. | [14](14-innovacion-abierta.md) |
| **Adoption Rate** | Usuarios activos / licencias contratadas. Meta > 75 %. | [18](18-kpi.md) |
| **Adoptadores tempranos** | 13,5 % de la curva de adopción; visionarios. | [08](08-curvas-de-la-tecnologia.md) |
| **Análisis morfológico** | Técnica creativa: descomponer un problema en componentes y combinar opciones. | [11](11-creatividad-y-proceso-creativo.md) |
| **ARR / MRR** | Ingreso recurrente anual / mensual. | [18](18-kpi.md) |
| **Árbol de decisión** | Técnica de Data Mining: modelo visual de reglas para clasificar o predecir. | [05](05-data-mining.md) |
| **Big Data** | Datos tan masivos, rápidos y complejos que las herramientas tradicionales no pueden procesarlos. | [06](06-big-data.md) |
| **Biomimética** | Técnica creativa: imitar estructuras y procesos naturales. | [11](11-creatividad-y-proceso-creativo.md) |
| **Brainwriting** | Generación de ideas escrita e individual antes de compartir; evita la censura en equipos jerárquicos. | [11](11-creatividad-y-proceso-creativo.md) |
| **Business Intelligence (BI)** | Conjunto de tecnologías, procesos y herramientas que transforman datos brutos en información accionable. | [04](04-business-intelligence.md) |
| **CAC** | Costo de adquisición de cliente = (marketing + ventas) / nuevos clientes. | [18](18-kpi.md) |
| **Cascada de OKR** | Definir OKR en la empresa y bajarlos a equipos como contribución real. | [19](19-okr.md) |
| **Change Failure Rate** | % de releases que requieren rollback o hotfix. Métrica DORA. | [18](18-kpi.md) |
| **Churn** | Clientes perdidos / total al inicio × 100. | [18](18-kpi.md) |
| **Ciberresiliencia** | Capacidad de recuperarse de un ataque (vs. solo prevenirlo). | [02](02-impactos-y-desafios.md) |
| **Ciclos económicos** | Oscilación del PIB: depresión → recuperación → auge; la innovación impulsa la recuperación. | [09](09-schumpeter-destruccion-creativa-y-ciclos.md) |
| **Clasificación** | Técnica predictiva: asigna elementos a categorías predefinidas. | [05](05-data-mining.md) |
| **Clustering** | Técnica descriptiva: agrupa datos sin etiquetas previas según similitud. | [05](05-data-mining.md) |
| **Code Coverage** | Líneas testeadas / total × 100. Meta > 80 %. | [18](18-kpi.md) |
| **Corporate Venture Capital (CVC)** | Cartera de inversiones de una gran empresa en múltiples startups simultáneamente. | [14](14-innovacion-abierta.md) |
| **Creatividad** | Capacidad de generar nuevas ideas y conceptos por medio de la creación, cambios y mejoras. | [11](11-creatividad-y-proceso-creativo.md) |
| **Curva de adopción** | Cómo distintos grupos adoptan una tecnología: 2,5 / 13,5 / 34 / 34 / 16 %. | [08](08-curvas-de-la-tecnologia.md) |
| **Curva S** | Evolución del desempeño de una tecnología: despegue lento, crecimiento acelerado, saturación (Christensen). | [08](08-curvas-de-la-tecnologia.md) |
| **Data Mining** | Proceso técnico y automatizado que descubre patrones ocultos en grandes volúmenes de datos con estadística e IA. | [05](05-data-mining.md) |
| **Data warehouse** | Repositorio central donde BI integra datos de distintas fuentes. | [04](04-business-intelligence.md) |
| **Deep learning** | Subcampo del machine learning basado en redes neuronales profundas. | [12](12-innovacion-tecnologica-e-ia.md) |
| **Defect Escape Rate** | Bugs en producción / total de bugs × 100. Meta < 5 %. | [18](18-kpi.md) |
| **Design Thinking** | Metodología centrada en el ser humano: empatizar, definir, idear, prototipar, testear. | [13](13-design-thinking.md) |
| **Destrucción creativa** | Proceso de transformación que acompaña a la innovación (Schumpeter). | [09](09-schumpeter-destruccion-creativa-y-ciclos.md) |
| **Doblin (10 tipos)** | Configuración (4), Oferta (2), Experiencia (4). | [10](10-gestion-de-la-innovacion.md) |
| **DORA metrics** | Deployment frequency, lead time, change failure rate, MTTR. | [18](18-kpi.md) |
| **Embudo de desarrollo** | Modelo cerrado y secuencial que filtra ideas (Wheelwright & Clark, 1992). | [14](14-innovacion-abierta.md) |
| **Estrategia de innovación** | Plan que vincula las mejoras novedosas con la estrategia comercial; hoja de ruta. | [16](16-proyectos-y-estrategia-de-innovacion.md) |
| **Gemelo digital** | Réplica virtual para simular escenarios antes de aplicarlos en la realidad. | [02](02-impactos-y-desafios.md) |
| **Gestión de la Innovación 2.0** | Liderazgo, inversión/procesos, estructura en red, estilos de liderazgo, fracaso, trabajo en equipo. | [10](10-gestion-de-la-innovacion.md) |
| **Hype Cycle (Gartner)** | Ciclo de expectativas: detonante, pico, abismo, pendiente, meseta. | [08](08-curvas-de-la-tecnologia.md) |
| **I+D+i** | Investigación + Desarrollo + innovación. | [12](12-innovacion-tecnologica-e-ia.md) |
| **IA agéntica** | Sistemas que no solo sugieren sino que ejecutan flujos de trabajo completos. | [02](02-impactos-y-desafios.md) |
| **IA estrecha / general** | Para una tarea específica (la actual) / que emularía la mente humana (teórica). | [12](12-innovacion-tecnologica-e-ia.md) |
| **Inbound / Outbound** | Absorber conocimiento externo / monetizar afuera el conocimiento interno. | [14](14-innovacion-abierta.md) |
| **Innovación** | Aplicación práctica y exitosa de nuevas ideas tecnológicas para mejorar la eficiencia o crear oportunidades ("el para qué"). | [01](01-tecnologia-e-innovacion-fundamentos.md) |
| **Innovación abierta** | Paradigma de Chesbrough (2003): el conocimiento entra y sale de la empresa. | [14](14-innovacion-abierta.md) |
| **Innovación alineada** | Conectar las metas de innovación con los objetivos de negocio. | [16](16-proyectos-y-estrategia-de-innovacion.md) |
| **Innovación arquitectónica** | Reorganiza componentes existentes de forma innovadora. | [16](16-proyectos-y-estrategia-de-innovacion.md) |
| **Innovación disruptiva** | Comienza en nichos y termina desplazando a los líderes. | [03](03-tecnologias-disruptivas.md), [12](12-innovacion-tecnologica-e-ia.md) |
| **Innovación incremental** | Pequeñas mejoras continuas sobre lo existente. | [01](01-tecnologia-e-innovacion-fundamentos.md) |
| **Innovación radical** | Cambios revolucionarios que crean mercados nuevos. | [01](01-tecnologia-e-innovacion-fundamentos.md) |
| **Innovación tecnológica** | Proceso de crear, mejorar o aplicar nuevas tecnologías para productos, servicios o procesos más eficientes. | [12](12-innovacion-tecnologica-e-ia.md) |
| **Iterar** | Repetir el ciclo de mejora sin cambiar el rumbo. | [17](17-lean-startup.md) |
| **Joint venture** | Emprendimiento conjunto entre organizaciones que comparten inversión, riesgo y beneficio. | [14](14-innovacion-abierta.md) |
| **Kitchin / Juglar / Kondratiev** | Ciclos de ≈3, ≈10 y 40–60 años. | [09](09-schumpeter-destruccion-creativa-y-ciclos.md) |
| **KPI** | Indicador cuantificable que evalúa cuán bien se alcanzan objetivos estratégicos en un período. | [18](18-kpi.md) |
| **Lead Time** | Tiempo desde commit hasta producción. | [18](18-kpi.md) |
| **Leading / Lagging** | KPI que predicen resultados (accionables) / que miden resultados ocurridos. | [18](18-kpi.md) |
| **Lean Startup** | Metodología de Eric Ries para reducir riesgo y desperdicio con prototipos, experimentación y aprendizaje. | [17](17-lean-startup.md) |
| **LTV / CAC** | Relación valor de vida del cliente / costo de adquirirlo; saludable ≥ 3:1. | [18](18-kpi.md) |
| **Machine learning** | Subcampo de la IA: sistemas que aprenden de los datos. | [12](12-innovacion-tecnologica-e-ia.md) |
| **MTTR** | Tiempo medio de recuperación ante falla. | [18](18-kpi.md) |
| **MVP** | Producto mínimo viable para probar hipótesis con usuarios reales. | [17](17-lean-startup.md) |
| **NPS** | % promotores − % detractores. | [18](18-kpi.md) |
| **OKR** | Objectives and Key Results: sistema que conecta metas aspiracionales con indicadores medibles. | [19](19-okr.md) |
| **Pivotar** | Cambiar aspectos clave del negocio cuando el mercado no valida. | [17](17-lean-startup.md) |
| **Proceso creativo** | Preparación, incubación, iluminación, verificación, adaptación y difusión. | [11](11-creatividad-y-proceso-creativo.md) |
| **Proyecto de innovación** | Esfuerzo planificado y estratégico para introducir cambios significativos que generen valor. | [16](16-proyectos-y-estrategia-de-innovacion.md) |
| **Reglas de asociación** | Técnica de Data Mining: qué elementos aparecen juntos (cesta de compra). | [05](05-data-mining.md) |
| **Regresión** | Técnica de Data Mining para predecir valores numéricos continuos. | [05](05-data-mining.md) |
| **SCAMPER** | Sustituir, Combinar, Adaptar, Modificar, Poner en otro uso, Eliminar, Revertir. | [11](11-creatividad-y-proceso-creativo.md) |
| **Self-Service BI** | Usuarios de negocio sin conocimientos técnicos consultan datos y crean informes. | [04](04-business-intelligence.md) |
| **SLA** | Acuerdo de nivel de servicio; el KPI como compromiso contractual. | [18](18-kpi.md) |
| **SMART** | Specific, Measurable, Achievable, Relevant, Time-bound (Doran, 1981). | [18](18-kpi.md) |
| **Spin-off** | Empresa nueva que se desprende de otra para explotar una tecnología. | [14](14-innovacion-abierta.md) |
| **Squad** | Equipo autónomo con su propio KPI (modelo Spotify). | [18](18-kpi.md) |
| **Tecnología** | Conjunto de saberes, técnicas y herramientas que permiten transformar el entorno ("el cómo"). | [01](01-tecnologia-e-innovacion-fundamentos.md) |
| **Tecnologías disruptivas** | Innovaciones que transforman radicalmente industrias y desplazan lo establecido con soluciones más accesibles. | [03](03-tecnologias-disruptivas.md) |
| **Text mining** | Análisis de datos no estructurados (textos) y sentimiento. | [05](05-data-mining.md) |
| **Time to Value (TTV)** | Días desde contrato hasta primer uso productivo. | [18](18-kpi.md) |
| **Unicornio** | Startup tecnológica valuada en más de USD 1.000 M antes de cotizar o ser adquirida. | [07](07-empresas-unicornio.md) |
| **VANI (BANI)** | Frágil, Ansioso, No lineal, Incomprensible (Jamais Cascio). | [15](15-entornos-vica-y-vani.md) |
| **VICA (VUCA)** | Volátil, Incierto, Complejo, Ambiguo. | [15](15-entornos-vica-y-vani.md) |
